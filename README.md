# Acceso-remoto-seguro
Demuestra con evidencia la diferencia de seguridad entre TELNET y SSH y deja el servidor de la organización accesible solo por SSH endurecido.
INSTRUCCIONES
• Laboratorio 10: TELNET en la red aislada del laboratorio, captura con Wireshark y análisis del tráfico en texto claro.
• Laboratorio 10: la misma sesión por SSH, captura y comparación del tráfico cifrado.
• Laboratorio 11: claves ed25519, sshd_config endurecido (sin root, sin contraseña, puerto y usuarios permitidos), scp/sftp y un túnel local.
• Instalar fail2ban, simular un ataque de fuerza bruta y registrar el bloqueo; completar la bitácora de IA.
• Informe técnico + bitacora IA todo con formato APA v7, también deben poner el enlace a su repositorio Github + presentación de Actividad en .pptx o html o pdf
